# من هنا

منصة عرض تفاعلية لمشروع تخرج عن التجارب السياحية في المزارع السعودية. React + Vite + CSS، عربية بالكامل واتجاه RTL ومتجاوبة.

**كل البيانات والأسعار والمواعيد والحجوزات والدفع تجريبية. لا توجد خدمات حجز أو دفع أو إرسال رسائل فعلية.**

## التشغيل

Node.js 22.12 أو أحدث:

```bash
npm ci
npm run dev
```

خادم Vite يستمع على `0.0.0.0:5173` مع تثبيت المنفذ. عند التشغيل على جهازك افتح العنوان الذي يطبعه Vite. المعاينة السحابية تحتاج أداة توجيه منفذ 5173؛ تشغيل الخادم وحده لا يضمن عمل بطاقة المعاينة في واجهة المحادثة. إذا كانت أداة المعاينة تمرر Host خارجيًا، حدد نطاقها الفعلي دون البروتوكول أو المسار في `MIN_HUNA_PREVIEW_HOST` قبل تشغيل Vite. لا تعطّل التحقق من أسماء المضيفين.

```bash
npm run build
npm run preview
```

نسخة الإنتاج على المنفذ 4173. لا تقدم ملفات المصدر بخادم ساكن، فـJSX يحتاج Vite. للنشر الساكن انشر مجلد `dist`؛ التنقل يستخدم روابط hash ولا يحتاج قواعد إعادة كتابة مسارات الصفحات. مسار Vite الأساسي هو `/-1/` ليتوافق مع اسم المستودع الحالي.

## الصفحات والتفاعلات

- `#/`: الصفحة الرئيسية، الصورة الأصلية، النبذة، شريط تجارب قابل للتمرير والأسهم، الخطوات والمزارع.
- `#/experiences`: بحث وفلاتر مشتركة للمنطقة ونوع التجربة والمدة، وحالة عدم وجود نتائج.
- `#/regions`: ست مناطق في البيانات التجريبية، وروابط إلى التجارب المفلترة.
- `#/experience/palms`: التفاصيل والصور القابلة للتبديل والأنشطة والمدة والسعر وزر الحجز. بقية التجارب تعمل بمعرّفاتها.
- `#/booking/palms`: التاريخ والوقت وعدد الأشخاص من 1 إلى 12 والاسم والجوال السعودي والبريد والموافقة على الشروط.
- `#/payment`: ملخص وحساب الإجمالي واختيار طريقة محاكاة فقط. لا توجد حقول بطاقات.
- `#/confirmation`: تأكيد ورقم حجز تجريبي وتفاصيله وإمكانية حذفه.
- `#/contact`: نموذج للزائر ونموذج لصاحب المزرعة. النتيجة توضح عدم الإرسال الفعلي.
- نافذة شروط الحجز والإلغاء باستخدام dialog، تدعم Escape وإرجاع التركيز.

الحجز محفوظ مؤقتًا في `sessionStorage` لهذه الجلسة فقط، دون إرسال للخادم. استخدم بيانات افتراضية، ثم زر حذف الحجز لإزالة بياناته. البيانات في `src/data.js`.

## الاختبارات

```bash
npm run build
npx playwright install chromium
# في طرفية أخرى بعد تشغيل Vite:
npm run test:browser
```

يمكن استخدام Chromium المثبت على نظام Linux:

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

لاختبار نسخة الإنتاج بعد تشغيل `npm run preview`:

```bash
TEST_URL=http://127.0.0.1:4173/-1/ CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

الاختبار يتحقق من عرض الصفحة والتمرير والفلاتر والمناطق والصور والتحقق من البيانات والشروط والإجمالي والدفع التجريبي وتحديث الصفحة وحذف الحجز ونموذج أصحاب المزارع، ومن عدم وجود تمرير أفقي أو أخطاء JavaScript أو صور مكسورة على مقاسي 390 و1280.

## الأصول والتصميم

جميع الصور في `public/images` من الملف المرفق، باستثناء `palm-pattern.svg` المرسوم بالكود. الصورة الأصلية الجديدة `Gemini_Generated_Image_r8critr8critr8cr.jpg` محفوظة باسم `hero.jpg`. تصاميم الواجهات مراجع بصرية فقط ولا تُستخدم خلفيات أو صفحات مصورة. الخريطة قص CSS تقريبي. الخطان Amiri وNoto Sans Arabic من Google Fonts مع بدائل محلية؛ لم يُرفق ملف خط خاص.

لم تُرفق تصاميم مستقلة لتواصل معنا أو الشروط. صور بعض البطاقات الإضافية الظاهرة في تصاميم التجارب والمناطق ليست ملفات مستقلة في الأرشيف، لذلك استخدمت الصور الأصلية المتاحة دون قصها من الواجهات. مناطق البيانات الست هي الرياض والقصيم والأحساء والطائف والجوف وعسير؛ لا يدّعي العرض تغطية جميع مناطق المملكة.

ملفات المرحلة السابقة (`src/main.jsx` و`src/styles.css`) وصفحة الاختبار (`src/preview-test.jsx` و`src/preview-test.css`) محفوظة. المدخل الحالي هو `src/app.jsx`، فلا تظهر صفحة الاختبار القديمة.


## GitHub Pages

تم إعداد `.github/workflows/deploy-pages.yml` لبناء `dist` ونشره تلقائيًا بعد كل دفع إلى `main` أو تشغيل يدوي.

1. افتح المستودع ثم **Settings → Pages**.
2. ضمن **Build and deployment → Source** اختر **GitHub Actions**.
3. افتح تبويب **Actions**، واختر **Deploy to GitHub Pages** ثم **Run workflow** على فرع `main` إذا لم يبدأ النشر بعد تفعيل Pages.
4. انتظر نجاح مهمتي `build` و`deploy`، ثم افتح الرابط المنشور من المهمة أو إعدادات Pages.

الرابط المتوقع: https://ghidaothman2002-ops.github.io/-1/

ضُبط `base` في Vite على `/-1/` وتستخدم الصور في JSX `import.meta.env.BASE_URL`. يعالج Vite مسارات الصور في CSS وHTML أثناء البناء. روابط الصفحات تستخدم hash وتعمل على Pages دون خادم إضافي. محليًا افتح مسار `/-1/` أيضًا. نجاح البناء المحلي لا يؤكد النشر العام؛ يلزم نجاح Actions والتحقق من الرابط.
