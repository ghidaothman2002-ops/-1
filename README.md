# من هنا

صفحة رئيسية عربية متجاوبة لمنصة تجارب سياحية في المزارع السعودية، مبنية باستخدام React وVite وCSS.

## التشغيل

يتطلب Node.js 22.12 أو أحدث.

```bash
cd /workspace/-1
npm ci
npm run dev
```

افتح `http://localhost:5173` عند تشغيل المشروع على جهازك. في بيئة سحابية تدعم تحويل المنافذ، افتح المنفذ 5173 من لوحة المعاينة أو المنافذ.

```bash
npm run build
npm run preview
```

معاينة نسخة الإنتاج تستخدم المنفذ 4173.

## المعاينة السحابية

خادم التطوير يستمع على `0.0.0.0:5173`، وخادم نسخة الإنتاج على `0.0.0.0:4173`. تم تثبيت المنافذ باستخدام `strictPort` حتى لا ينتقل Vite إلى منفذ آخر عند انشغال المنفذ المطلوب. وجّه أداة المعاينة إلى المنفذ 5173 عند تشغيل `npm run dev`.

إذا مررت أداة المعاينة اسم نطاق خارجي إلى Vite، أضف اسم النطاق الفعلي دون البروتوكول أو المسار:

```bash
MIN_HUNA_PREVIEW_HOST=your-preview-host.example npm run dev
```

لا يُستخدم النطاق أعلاه حرفيًا؛ استبدله بنطاق المعاينة الحقيقي. لا توجد حاجة إلى هذا المتغير عند الوصول عبر localhost. يجب فتح الموقع من خادم Vite، وليس فتح `index.html` مباشرة أو تقديم ملفات المصدر بخادم ملفات ساكنة؛ JSX يحتاج معالجة Vite. لتقديم الملفات بخادم ساكن استخدم مجلد `dist` بعد البناء.

## الصور والنطاق

الصور والشعار في `public/images` من الملفات الأصلية المرفقة. لم تُستخدم لقطة التصميم كخلفية. صورة الغروب الرئيسية لم تُرفق منفصلة؛ الصورة الرئيسية الحالية مؤقتة من صورة الأحساء الأصلية. خريطة السعودية مرسومة بقص CSS تقريبي لصورة عسير. نمط النخيل في التذييل مرسوم بعناصر SVG.

الصفحة الرئيسية فقط: التنقل الداخلي والبحث وتبديل ترتيب التجارب وعرض معلومات البطاقات تعمل. الحجز الفعلي وصفحات التفاصيل ليست ضمن هذه المرحلة. الخطوط تُحمّل من Google Fonts مع خط بديل محلي عند عدم توفر الشبكة.
